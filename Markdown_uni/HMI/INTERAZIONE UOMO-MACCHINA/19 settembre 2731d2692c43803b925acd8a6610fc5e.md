# UX Design

Si riferisce a come il prodotto *si sente* e differisce completamente dal graphic design tradizionale.

Ci si concentra sulla struttura logica dietro agli elementi con cui interagisci.

Lo UX designer tra diversi approcci risolve problemi user-specific.

Il design dell’esperienza utente è il processo mirato ad aumentare la soddisfazione e la fedeltà del cliente migliorando l’usabilità.

UX designer utilizzano strumenti come la **heatmap** per aiutare a ricavare dati significativi.

## UX Designer

Il Designer ha l’obiettivo di far vivere all’utente del suo prodotto, la miglior esperienza possibile.

Però non si può fare design di User Experience, si può solo fare design **per** la user experience.

Lo UX Design dunque parte dall’analisi e comprensione delle esigenze dell’utente e **non** dalle specifiche funzionali di prodotto.

# User Interface Design (UI design)

Dallo UX design esce l’input per lo UI Design.

Lo UX crea uno schema di interazione che lo UI Designer trasformerà in un interfaccia utente.

## UI Designer

Non si cura dell’esperienza utente ad alto livello, ma fa si che l’esperienza abilitata nell’utente sia la migliore possibile.

**Es**. Lo UX mi dice che un pulsante in basso a sinistra è inconveniente per lo user, lo UI lo seguendo questa direttiva.

**Es**. Accorgimento UX: nelle App di home-banking non hai mai la conferma in basso a sinistra in modo tale da evitare shopping compulsivo. Solitamente devo almeno scrollare la pagina. Totalmente diversa un’app per shopping online.
