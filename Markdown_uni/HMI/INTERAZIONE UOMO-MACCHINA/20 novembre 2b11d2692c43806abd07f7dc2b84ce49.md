# Interfacce

È un punto di contatto tra 2 sistemi che tentano di comunicare.

Nel nostro caso è il punto dove avviene lo scambio tra l’utente e la macchina.

![image.png](20%20novembre/image.png)

Le interfacce devono essere adatte all’utente. 
**Es**. Un coltello per un utente con disabilità deve essere adatto per un uso facilitato.

## Interfacce utente

Si abbrevia con UI. (da non confondere con User Interaction ..)

Lo scopo dell’interfaccia non è mettere a disposizione dell’utente ogni feature del prodotto. (se ho 1000 funzioni non posso avere 1000 bottoni).

Devo usare la UI per semplificare l’uso del prodotto e deve aiutare a trasformare il modello fisico in un modello mentale.

![image.png](20%20novembre/image%201.png)

**Es**. Nel 1967 poteva essere pilotato solo ed esclusivamente da un ingegnere di quel campo. Più si va avanti più si chiede agli umani di passare alla pianificazione.

Ora praticamente è più un taxi, e la UI da informazioni per l’astronauta.

![image.png](20%20novembre/image%202.png)

**Es**. L’interfaccia a dx offre anche più prodotti ma il modo in cui è mostrato è nettamente superiore a dx

## HMI (Human machine interface)

Le UI sono composte da uno o più layer fisici. Una HMI può avere hardware per input fisici. Un device che implementa HMI viene chiamato Human Interface Device (HID)

**Es**. Monitor e touchpad/mouse sono gli HID più comuni. Per un assistente vocale è diverso.

![image.png](20%20novembre/image%203.png)

Interfacce si organizzano in base ai sensi che utilizzano per stabilire interazione tra umano e macchina:

- Tactile UI
- Visual UI
- Auditory UI
- Oflactory UI
- Gustatory UI
- Equilibrial UI

La maggior parte delle interfacce moderne non segue più queste classificazioni. 
**Es**. Un tablet è considerato come un interfaccia unica dove vedo, sento, e tocco. Mi permette un interazione multi-sense.

Come classifico le interfacce uomo-macchina?

Oggi sono dette CUI o Composite User Interface, perché basano interazione su più sensi.

GUI è la più comune (Graphical User Interface), ma il termine originale nasce negli anni 70 dove un interfaccia visiva era esclusivamente video senza audio. Il termine corretto sarebbe MUI (Multimedia User Interface)

Però estendere interfacce con più canali non è sempre una buona idea. 
**Es**. Una volta Instagram aveva di default l’audio dei video acceso. Adesso è stato rimosso perché l’audio paradossalmente riduceva l’uso del prodotto perchè i social vengono utilizzati in qualsiasi contesto (anche quelli privati e riservati).

Tre tipi di CUI:

- **Standard**: La realtà è tutta trasformata secondo il modello concettuale.
**Es**. Word è stile libro ma tradotto in digitale.
- **Augmented**: Impone un interfaccia su una vista reale.
- **Virtual**: Mimo in modo più realistico possibile ma in modo totalmente digitale.

Se creassimo un’interfaccia che utilizza tutti i sensi dell’uomo si chiamerebbe Qualia Interface

Si è standardizzato utilizzare 3N con N il numero di sensi utilizzati.

Es. Microsoft Reactable è interfaccia auentata 3S (MUI)
