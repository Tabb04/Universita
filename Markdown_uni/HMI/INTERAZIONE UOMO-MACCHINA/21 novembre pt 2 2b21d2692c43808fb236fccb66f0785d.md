# Natural User Interface

Interfaccia ideale. Interfaccia dove lo scambio uomo-macchina è naturale (innata).

**Es**. Scroll di un documento, pinch to zoom.

Hanno una learning queue molto ripida. Utente diventa velocemente esperto, ma la curva satura velocemente.

La NUI è un evoluzione delle GUI dove l’interazione è diretta e assoluta e soprattuto è intuitiva (fa leva sulle conoscense pregresse dell’utente).

Le funzionalità di base non comprendono pienamente tutta la popolazione, ma la maggior parte degli utenti si.

## In breve

Una NUI è una user Interface che si percepisce naturale nell’uso perchè è adatta alle skill e il contesto dello user.

Prende vantaggio delle skill dello user  e ha un chiaro learning path per esperti e novizi.

## Reality Based Interfaces

Una strategia sono le RUI, dette anche Reality-Based Interfaces.

Es. Dispositivi indossabili che rendono oggetti nel mondo reale cliccabili.

Senza RUI si può provare a raggiungerere una NUI limitando  le funzionalità e customizzazione. (così lo user deve imparare molto poco).
